# Sapremo Warehouse Manager

Современная система управления складом Бишкекского распределительного холодильника. Приложение спроектировано с упором на надежность, оффлайн-доступность и кроссплатформенность, предлагая пользователю бесшовный опыт как в браузере, так и в виде нативного десктопного приложения.

## О проекте

Warehouse Manager решает ключевые задачи складского учета: приемка товаров от завода, выдача заказов водителям, обработка возвратов, финансовый учет (долги перед заводом и оплата) и генерация аналитических отчетов.

Главная архитектурная особенность - подход **Offline-first**. Приложение способно полноценно работать без доступа к интернету, локально сохраняя все изменения, и автоматически синхронизировать их с сервером при восстановлении связи.

## Технологический стек

Мы используем современные инструменты для обеспечения высокой производительности и удобства разработки:

- **Ядро**: React 18 + TypeScript + Vite 5.
- **UI и дизайн**: Ant Design 5 (с кастомной дизайн-системой), Tailwind CSS 3. Реализованы плавные переходы между светлой и темной темами в стиле Apple.
- **Управление состоянием**: Zustand 4 (для глобального стейта и очереди синхронизации) + TanStack Query 5 (для работы с серверным состоянием).
- **Роутинг**: React Router 6.
- **База данных (Offline)**: Dexie 4 (обертка над IndexedDB).
- **Сетевое взаимодействие**: Axios (HTTP запросы), SockJS (WebSocket для real-time обновлений).
- **Локализация**: i18next (поддержка кыргызского, русского и английского языков).
- **Десктопная версия**: Tauri v2 (Rust).
- **PWA**: vite-plugin-pwa для установки веб-версии как прогрессивного веб-приложения.

## Архитектура и Offline-first

В основе приложения лежит паттерн локальной очереди синхронизации (`syncQueue`).

1. **Локальное чтение и запись**: Все операции чтения и изменения данных сначала применяются к локальной базе данных `IndexedDB` через `Dexie`. Это гарантирует мгновенный отклик интерфейса (Zero Latency).
2. **Очередь задач**: Каждое действие модификации данных (создание, обновление, удаление) записывается в таблицу `syncQueue` как задача (SyncTask).
3. **Фоновая синхронизация**: Глобальный стор `useSyncStore` отслеживает состояние сети (`window.addEventListener('online')`). Как только появляется интернет, запускается фоновый процесс отправки накопившихся задач на бэкенд.
4. **Real-time обновления**: При наличии сети приложение слушает WebSocket-канал. При получении события от сервера (например, завод подтвердил приемку) вызывается функция `kickSync()`, которая незаметно подтягивает актуальные данные.

## Интерфейс и возможности

Веб-интерфейс спроектирован для максимальной продуктивности кладовщика:

- **Дашборд**: Сводная статистика за день, график отгрузок и приемок.
- **Склад (Остатки)**: Мониторинг текущих остатков в режиме реального времени.
- **Приемка от завода**: Фиксация поступивших товаров, возможность частичной приемки.
- **Заявки водителей**: Обработка, сборка и выдача заказов водителям. Генерация и печать накладных (PDF).
- **Возвраты**: Оформление возвращенного или бракованного товара.
- **Оплаты и долги**: Трекинг оплат заводу и вычисление текущей задолженности.
- **Отчеты**: Выгрузка детальной статистики (выданное водителям, малые остатки, возвраты).

## Десктопное приложение (Tauri)

Помимо веб-версии, проект компилируется в полноценное нативное приложение для Windows, macOS и Linux с помощью **Tauri**. 

Tauri использует встроенный в ОС веб-движок (WebView2 на Windows), что делает приложение невероятно легким (бинарник весит всего пару мегабайт) и быстрым. В десктопной версии локальная база данных IndexedDB работает изолированно, что требует первичной синхронизации при первом входе, но взамен предоставляет максимальную стабильность и глубокую интеграцию с ОС.

## Разработка

### Установка зависимостей
```bash
npm install
```

### Запуск веб-версии
```bash
# Копируем конфиг окружения
cp .env.example .env.local

# Запускаем локальный dev-сервер
npm run dev
```

### Сборка веб-версии (PWA)
```bash
npm run build
```

### Запуск и сборка Tauri (Десктоп)
Убедитесь, что у вас установлены [Rust](https://rustup.rs/) и инструменты сборки C++.

```bash
# Режим разработки Tauri
npm run dev:tauri

# Сборка финального .exe / .msi файла
npm run build:tauri
```

## Особенности реализации UI

Приложение полностью переведено на 3 языка (включая кыргызский, который не поддерживается библиотекой Ant Design из коробки). Для решения этой проблемы был написан кастомный провайдер локали, который расширяет базовый пакет `ru_RU` и переопределяет компоненты (таблицы, пагинацию) для корректного отображения на кыргызском.

- **Токены**: Все базовые стили (цвета, отступы, шрифты) вынесены в CSS-переменные для легкой кастомизации.
- **Плавный Dark Mode**: Переключение тем реализовано через класс `theme-dark` на `body`. В файле `index.css` описаны глобальные правила `transition` для плавного перетекания цветов фона и текста без резких вспышек (как в iOS). Иконки и переключатели используют векторные микро-анимации.
- **Адаптивность**: Интерфейс адаптивен и автоматически подстраивается под мобильные устройства (PWA), предоставляя удобный вид на экранах терминалов сбора данных (ТСД) или планшетах.
